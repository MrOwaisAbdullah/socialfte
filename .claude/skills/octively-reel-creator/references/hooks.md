# Hook Line Library

Octively-specific hook lines, organized by archetype (see `retention-rules.md` for why these
archetypes work) and mapped to the value prop each one sells. Use these as-is or as templates —
they're already checked against the copy rules (no em dash, no rupee symbol, "AI agent" not
"chatbot"). Swap the bracketed numbers only from verified `CLAUDE.md` pricing facts.

## Value prop → archetype map

| Value prop | Best archetype | Footage needed |
|---|---|---|
| Client keeps asking for status updates | POV / Realism | None (text-only, reuse `Scene1Problem`-style beat) |
| Speed to build/launch | Specific Outcome | `admin-02-create-form`, `admin-03-embed-copy` |
| White-label client portal | Curiosity Gap | `portal-01` through `portal-04` |
| Free-forever plan (no trial, no card) | Contrarian | None (text-only, brand reel) |
| Price gap vs. competitors | Specific Outcome / Contrarian | None (text-only, comparison reel) |
| Retainer-upsell math for existing clients | Specific Outcome | None or `landing.png` (text-heavy, business-pitch reel) |
| Knowledge base / train on docs | Curiosity Gap | `admin-06-knowledge` (unused in main demo) |
| Human handoff / "doesn't guess" | Contrarian | `admin-07-unanswered` (unused in main demo) |

## Reel 1 — The Pain (POV / Realism)

- "Your client. 9pm. Asking for the numbers again."
- "Every freelancer knows this text message."
- "The client doesn't want a report. They want an answer."

Payoff line (by frame 90): "So we built an AI agent that answers before they have to ask."

## Reel 2 — 60-Second Build (Specific Outcome)

- "I built a client-ready AI agent in under a minute."
- "Name it. Point it at a website. Done."
- "This is the whole setup. Sixty seconds."

Payoff line: show the embed-copy beat — "One line of code. Any client site."

## Reel 3 — Portal Reveal (Curiosity Gap)

- "Your client stopped texting you for updates."
- "The feature that ends the 'any update?' messages."
- "Give your client their own login. They stop calling you."

Payoff line: "Their own portal. Conversations, leads, exports. No status-update calls."

## Reel 4 — Free Plan Callout (Contrarian, text-only)

- "Every AI agent tool gives you a 14-day trial. We didn't."
- "No credit card. No countdown. No catch."
- "Free means free. Not '14 days and then pay.'"

Payoff line: "Free plan, forever. Rs0. Upgrade only when you need more."

## Reel 5 — Retainer Math (Specific Outcome, business-pitch)

Targets freelancers/agencies who already have client relationships — the core Octively pitch.

- "You already have the client. Here's a new Rs10,000/month from them."
- "Same client. Same website. One new service you're not charging for yet."
- "Add an AI agent to a site you already built. Charge a retainer for it."

Payoff line: "The tool costs Rs2,500/month flat. You charge the client Rs10,000-20,000. No new client needed."

Structure note: this one is closer to a mini case-study than a UI demo — lean on bold typographic
statements (dollar/rupee figures large, Sky-Teal highlight on the number) rather than product
footage, since the hook is about the *business model*, not the interface.

## Price-gap comparison lines (Specific Outcome / Contrarian)

Use verified `CLAUDE.md` numbers only — never round up competitor prices or round down Octively's.

- "Stammer.ai: $197/month. Octively: $15/month. Same job."
- "Three tools. One price makes sense for a Pakistani freelancer."
- "$197, $220, $360 a month. Or Rs2,500. You do the math."

## General hook-writing checklist

- [ ] 5-8 words, reads in under 1 second
- [ ] No "Introducing", "Here's", "Check out" — these are the generic-reveal failure mode (~12% retention)
- [ ] Says "AI agent" / "AI agent builder", never "chatbot"
- [ ] No em dash, no ₨/₹ glyph
- [ ] One concrete detail (a number, a time, a named competitor) beats an abstract claim every time
