# Python deps for the SocialFTE agent/worker stack (Python 3.11+).
# Install into a venv at the repo root:
#     python -m venv venv
#     venv/Scripts/python -m pip install -r requirements.txt      # Windows
#     ./venv/bin/pip install -r requirements.txt                  # macOS/Linux
# Then run tools as `python tools/media/<tool>.py ...` with that venv active.
#
# Also required on PATH (not pip): ffmpeg + ffprobe, and Node.js (for the Remotion render step).
